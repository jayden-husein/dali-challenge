## Agent skills

### Issue tracker

Issues live in GitHub Issues (`jayden-husein/dali-challenge`) via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

## Process log

Log each session in `NOTES.md` as you go: the user's decisions and reasoning quoted verbatim, your recommendations and why, and skills/tools used. NOTES.md stays uncommitted unless the user asks. The user writes all README and reflection prose themselves (DALI AI policy); review it, never draft it.

Before running tests or the app locally, read `docs/agents/dev-setup.md`.
