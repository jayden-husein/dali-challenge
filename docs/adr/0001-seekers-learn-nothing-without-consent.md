# Seekers learn nothing without the Registrant's live consent

Some people in this disaster don't want to be found (someone who fled an abusive partner, someone afraid to give their real name), and anyone can search from any device. So a Seeker never sees a Registrant's shelter, location, or Visibility, and every contact goes through a Contact Request that a Volunteer reads to the Registrant in person. Only a "yes" sends the Seeker anything, and the Registrant chooses what that message says. Every other outcome (declined, wrong person, couldn't find them, Departed) shows the Seeker the same "passed on" status, and every empty search shows the same message, whether nobody matched or the person is Not findable.

## Considered Options

- **Three Visibility levels** (findable / ask-me-first / not listed): rejected. Once ask-me-first was hidden from Seekers, it behaved the same as findable, and a "findable shows location" level is the feature an abuser would exploit.
- **Telling the Seeker "not the person you're looking for"**: rejected. An abuser could send a request to every candidate and rule them out one by one until only the target is left "passed on". Grouping requests into batches doesn't fix this, because a batch of one gives the same answer.
- **"Not registered" on empty searches**: rejected. It's either false for Not findable people (so a real family may stop looking) or only shown when true (which leaks that a registered person is hiding).

## Consequences

Honest Seekers get less closure: a "passed on" request might mean a wrong match, a refusal, or a person nobody could locate. The status page and the empty-search message tell them to keep searching instead.

The duplicate check on Register is the one Volunteer view that reaches past its own shelter. It shows other shelters' Findable, non-Departed Registrants, whom anyone can already find by searching, plus everyone at the Volunteer's own shelter. Another shelter's Not findable or Departed Registrants never appear, so a Shelter Code reveals no more about other shelters than search does.
